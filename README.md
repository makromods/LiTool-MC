⚡ LiTool MC

LiTool MC is a powerful Minecraft Plugin Development Toolkit designed for Termux.

Build, manage, and develop Minecraft plugins directly from your Android device. 🚀

---

🚀 Installation

Open Termux and run this command:

curl -fsSL https://raw.githubusercontent.com/makromods/LiTool-MC/main/install.sh | bash

▶️ Run LiTool MC

After installation, simply run:

litool

That's it! 🎉

---

🛠️ Features

- 📦 Install Plugin Development Packages
- 🏗️ Create Minecraft Plugin Projects
- 🔨 Build Plugins into ".jar"
- ⚡ Command Generator
- 🎧 Listener Generator
- 📄 "plugin.yml" Generator
- ⚙️ "config.yml" Generator
- ☕ Java Class Generator
- 📚 Plugin Templates
- 📥 Install Plugin to Server
- 📁 Project Manager
- 🖥️ Server Tools
- 🔍 Environment Checker
- 🔄 Update Support

---

📱 Designed for Termux

LiTool MC lets you create Minecraft plugins directly from your Android phone using Termux.

No PC required for the basic development workflow.
