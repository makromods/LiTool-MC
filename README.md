# ⚡ LiTool MC

Minecraft Plugin Development Toolkit for Termux.

## 🚀 Installation

Run this command in Termux:

```bash
curl -fsSL https://raw.githubusercontent.com/makromods/LiTool-MC/main/install.sh | bash
```

## ▶️ Run LiTool MC

After installation, run:

```bash
litool
```

That's it! 🎉

## 🛠️ Features

- 📦 Install Plugin Development Packages
- 🏗️ Create Minecraft Plugin Projects
- 🔨 Build Plugins into `.jar`
- ⚡ Command Generator
- 🎧 Listener Generator
- 📄 `plugin.yml` Generator
- ⚙️ `config.yml` Generator
- ☕ Java Class Generator
- 📚 Plugin Templates
- 📥 Install Plugin to Server
- 📁 Project Manager
- 🖥️ Server Tools
- 🔍 Environment Checker
- 🔄 Update Support

## 📱 Designed for Termux

Create and manage Minecraft plugins directly from your Android device.
